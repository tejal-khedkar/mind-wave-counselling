# MindWave Counselling

Source for **https://www.mindwavecounselling.com** — a static site hosted on GitHub Pages, with a Google Apps Script backend powering the booking form (Google Calendar + Google Sheets + Gmail).

> Looking for the non-developer, day-to-day owner's guide (adding slots, sending confirmations, pricing, DNS, renewals)? See [SITE-GUIDE.md](SITE-GUIDE.md).

---

## Stack

- **Frontend:** plain HTML / CSS / JS, built from partials with a tiny Node build script
- **Hosting:** GitHub Pages, served from `main` branch at the repo root
- **Domain:** `mindwavecounselling.com` (Squarespace Domains) → GitHub Pages via A + CNAME records; `CNAME` file in repo pins the custom domain
- **Email:** Google Workspace (`tejalkhedkar@mindwavecounselling.com`)
- **Backend:** Google Apps Script web app in [gas/Code.gs](gas/Code.gs); frontend talks to it via `APPS_SCRIPT_URL` in [main.js](main.js)

## Making changes

### 1. Edit a partial, never `index.html`

Open the file in `sections/` that corresponds to the area you want to change (table in [SITE-GUIDE.md §4](SITE-GUIDE.md#4-updating-website-content)). `index.html` is regenerated on every build — any direct edit will be overwritten.

### 2. Rebuild `index.html`

```bash
node build.js
```

`build.js` reads `index.template.html` and replaces each `<!-- INCLUDE: path -->` marker with the contents of that file. No dependencies, no `npm install`.

### 3. Preview locally

Any static server works. Quickest option:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000. Note: the booking form hits the live Apps Script URL, so form submissions from localhost will create real calendar/sheet entries unless you point `APPS_SCRIPT_URL` in [main.js](main.js) at a test deployment.

### 4. Commit and push

```bash
git add .
git commit -m "describe the change"
git push
```

GitHub Pages rebuilds on push to `main` — the live site updates in ~1–2 minutes. There is no CI; whatever is on `main` is what ships.

## Changing the Apps Script backend

The script in [gas/Code.gs](gas/Code.gs) is a **mirror** of what runs in Google Apps Script — the deployed copy lives at script.google.com, not in this repo. To change backend behaviour:

1. Edit `gas/Code.gs` here (so the repo stays the source of truth) and in the Apps Script editor.
2. In the Apps Script editor: **Deploy → Manage deployments → Edit → New version → Deploy**.
3. Copy the new Web App URL and update `APPS_SCRIPT_URL` at the top of [main.js](main.js).
4. `node build.js`, commit, push.

Deployment settings must stay as: **Execute as:** Me (owner account), **Who has access:** Anyone. The script also requires the Google Calendar advanced service enabled. Full redeploy details in [SITE-GUIDE.md §7](SITE-GUIDE.md#7-managing-the-google-apps-script).

## Conventions / gotchas

- **Do not edit `index.html` directly** — it's generated. The build script writes a `DO NOT EDIT` banner at the top as a reminder.
- **Do not rename CSS classes or `id=` attributes** without updating `style.css` and `main.js` — anchors (`#about`, `#booking`, etc.) and JS selectors depend on them.
- **Pricing** lives in `sections/contact.html` (search for `.si-row`). Session types in the booking dropdown live in `sections/booking.html` under `<select id="bt">`.
- **Favicon set** is in `assets/favicon_io/`; regenerate via favicon.io if the logo changes.
- **CNAME file** must contain `www.mindwavecounselling.com` and must not be deleted — GitHub Pages uses it to serve the custom domain.
- **DNS** (A records to GitHub Pages + CNAME for www) is managed in Squarespace, not here. See [SITE-GUIDE.md §8](SITE-GUIDE.md#8-domain--email-management).

## Common tasks

| Task | Steps |
|------|-------|
| Change copy on a section | Edit `sections/<name>.html` → `node build.js` → commit → push |
| Change price | Edit `.si-row` in `sections/contact.html` → build → push |
| Add/remove a booking session type | Edit `<select id="bt">` in `sections/booking.html` → build → push |
| Swap the logo | Replace `assets/logo-8.png`, regenerate `assets/favicon_io/` → commit → push |
| Change social links | Edit `sections/social.html` → build → push |
| Change booking confirmation email | Edit `gas/Code.gs`, redeploy script, update `APPS_SCRIPT_URL` in `main.js` → build → push |
| Add a new page | Create `foo.html` at repo root (standalone — not required to use `sections/`) → commit → push |

- Node.js (any recent version — the build uses only `fs` and `path`)
- Git with push access to this repo
